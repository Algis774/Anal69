# Фонарь

Простое Android-приложение: одна кнопка включает и выключает вспышку. При включении произносится фраза «Ебать ты петух» через русский системный синтез речи Android.

## Получение APK
Откройте вкладку Actions в репозитории GitHub. После успешного workflow скачайте артефакт Fonar-debug-apk. Внутри будет app-debug.apk.

Голос и тембр зависят от установленного на телефоне русского движка синтеза речи. Приложение слегка повышает высоту и скорость голоса.
